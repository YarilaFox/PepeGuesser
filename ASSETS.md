# Assets and permissions

This private review repository contains the original PepeGuesser map tiles, panorama images, game sounds, and interface assets. They are included so the game can be tested as it is, not replaced with a synthetic demonstration.

The Apache-2.0 software license does not automatically cover these assets, the Minecraft worlds, player builds, server branding, or other third-party content. Before making this repository public, confirm permission to redistribute them and document the applicable credits and terms. If permission cannot be confirmed, keep those assets outside the public repository and provide a separately licensed asset pack.

The three old sample locations in the source pointed to missing panoramas. This extraction uses the complete panorama folders under `backend/public/pepeguessr/panoramas/` as its playable location set.
